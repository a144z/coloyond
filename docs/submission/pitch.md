# Coloyond — canonical pitch copy

Use this copy instead of the retired Kotlin/Glider deck. All current presentations should describe the same shipped product.

## 1 — Your portfolio as one picture

A shareable, visual portfolio composition built for the mobile web and powered by Solana. Set a value mix, generate its visual identity, share a PNG and start the next remix.

## 2 — A mix you can work with

Portfolio percentages are easier to understand when they respond. Slide a weight, lock a target and watch the remaining budget normalize. Orbit, Prism and Stack compositions turn the target into a recognizable card.

## 3 — One UI, mobile everywhere

React and TypeScript at `/app`; a Gradle-built Capacitor Android APK packages that same UI. Native bridges handle app lifecycle, status bar and PNG file sharing. Kotlin/Jetpack Compose is retained only as a historical prototype. External wallet approval uses MWA/Wallet Standard integration; a real-device approval recording remains an acceptance item.

## 4 — Prices move; the mix responds

In a fee-free illustration, start with $1,000 at SOL 40%, ETH 20%, dUSD 40%. SOL rises 20%, ETH falls 20%. Value becomes $1,040 and weights drift to about 46.15%, 15.38%, 38.46%. Sell $64 of overweight SOL, buy $48 of ETH and add $16 to dUSD to restore target values in the model. Actual execution includes fees, rounding, liquidity, verified-price and scheduling constraints; this animation is not a recorded trade or a profit claim.

## 5 — Evidence behind the mechanics

The current vault program is executable on devnet. The proof snapshot includes retrievable successful settlement signatures and pre/post SPL balances, including multi-leg rebalances. Source contains on-chain custody/share mints, scheduled ER planning and authenticated atomic base-layer settlement. This proves more than a roadmap; it still does not establish source/binary audit parity, mainnet asset backing, continuous keeper uptime or APK-origin MWA execution. New oracle hardening passes host tests and an SBF build; the compiled review packet is available, pending an authorized upgrade.

## 6 — A repeatable creative loop

Compose → generate → export/share → open an unsigned remix draft → make it yours. Users can return to inspect drift and confirmed activity, update targets or issue a new visual card. These are retention hypotheses, not fabricated retention statistics. Pilot metrics: first export activation, recipient draft/remix completion and week-one return-to-inspect/export.

## 7 — Try it; inspect the proof

Open `/app`, install the signed debug APK, watch the 62-second music-driven film with its readable timed visual transcript, inspect the actual browser recording, and reproduce the tests/RPC snapshot. Core vault execution does not depend on Glider; no partnership, instant general wallet buy/sell or mainnet performance claim is made. Judge the demonstrated devnet product and its explicit remaining release checks.
