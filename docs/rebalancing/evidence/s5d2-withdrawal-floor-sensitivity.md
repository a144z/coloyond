# S5D2 — mark shock and integer withdrawal sensitivity

**Status:** synthetic accounting candidate evidence only. It selects no oracle, withdrawal, fairness, fee, or risk policy and does not prove Anchor/SPL CPI parity.

## Model

`tools/rebalancing/etf-economics/withdrawal_floor_sensitivity.py` combines independent single-asset mark shocks with partial in-kind withdrawals. For each asset, a partial burn pays `floor(reserve_units × burned_shares / total_shares)` base units. An exact final burn returns every remaining base unit. All NAV calculations use exact rational arithmetic and the fixed USDC/BTC/SOL marks of $1/$50,000/$100 before shock.

The 216-row grid crosses three inherited synthetic reserve profiles, each asset shocked independently at -50%, -10%, +10%, or +50%, and five partial burns plus exact full exit. It uses classic SPL integer units, 6/8/9 decimals, and the finite share/reserve inputs defined in the sibling floor model. The CSV is regenerated by running the script. SHA-256: `f71d9c1e181a92352f9465eb5e0bf47eb4a52582f0e08b5e0e1093e9a86db32a`.

## Results and limits

All 216 cases conserve each reserve exactly, pay no more than custody, and have a zero NAV accounting residual. Partial-redemption floor dust is the unfilled fraction of the redeemer's pro-rata entitlement; it remains in the reserve and is not a loss. Its maximum marked value in this finite grid is approximately `$0.000750997749`. Exact full burns return all remaining units and leave no shares or dust.

Six focused standard-library tests cover the integer reference, reserve conservation, marked-value accounting, full exit, deterministic grid and CSV, invalid inputs, and a near-`u64` reserve/share boundary. The resulting NAV/share changes are properties of these selected marks and integer floors, not fairness guarantees or materiality thresholds. The model excludes oracle confidence/freshness, actual Pyth updates, transfers and transaction fees, Token-2022 extensions, account constraints, contract arithmetic, and CPI behavior. S5A retains withdrawal-policy ownership; S5E must reconcile the frozen formula against actual SPL CPI balances.
